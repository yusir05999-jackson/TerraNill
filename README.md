# TerraNill ·《绿脉》（暂定名）

> 一款以卫星影像为视角、以生态修复为玩法的 2D 单机游戏——你扮演一套轨道生态修复系统，让荒芜的大地重新变绿。

## 这是什么

遥感科学与技术专业本科生的独立游戏实验：把专业课里的变化检测、NDVI 植被指数、DEM 地形分析做成游戏机制，并用 AI 工具（编程助手、AI 绘图/音乐）辅助一个人完成开发，全程公开开发日志。

## 玩法核心循环

**引水 → 润土 → 种植 → 扩散 → 验收**：挖渠引水（基于高度场的水文模拟），湿润土地，播种，植被自然蔓延，区域 NDVI 达标即修复成功。修复过程中穿插"变化检测"限时任务——对比前后两张卫星影像，找出退化区域。

## 快速开始（第 1 周原型：水文模拟）

需要 [Godot 4.x](https://godotengine.org/download)。

1. 克隆本仓库，把 `src/water_sim.gd` 和 `src/water_view.gd` 放进你的 Godot 项目
2. 新建场景，根节点搜索并添加 **WaterView**，按 F6 运行当前场景
3. 建议窗口设为 768×768（项目设置 → 显示 → 窗口）
4. 操作：**左键**注水 · **右键**挖渠 · **Shift+左键**抬升地形

`WaterSim` 是核心：128×128 高度图上的元胞自动机，按总水位（地形 + 水深）向 4 邻格流动，先算全部流向、再统一更新，质量守恒。

## 开发路线（8 周）

| 阶段 | 周期 | 目标 |
|---|---|---|
| 原型验证 | 第 1-2 周 | 水沿高度图流动、点出湖泊与小河 |
| 核心循环 | 第 3-4 周 | 湿润→种植→扩散→NDVI 渐变，一张地图通关 |
| 内容与关卡 | 第 5-6 周 | 5-6 张地图、变化检测任务、无人机漫游视角 |
| 润色与首发 | 第 7-8 周 | UI、音乐、叙事外壳，itch.io 免费上架 |

**止损护栏**：若第 2 周末核心手感不成立，回退为纯变化检测解谜版，保证 8 周内出成品。
