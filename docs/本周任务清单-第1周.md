# 《绿脉》第 1 周任务清单

> 本周总目标（方案里程碑）：**实现水沿高度场向低处流动、低洼处聚积，并形成固定河道。**

## P0 — 必做（核心原型）

- [ ] **搭好水文模拟骨架**：128×128 高度图已能渲染，在其上维护一张"水深场"，初始随机或手动点几处水源
- [ ] **实现元胞自动机流动**：按总水位（地形高度 + 水深）计算每个格子向 4 邻格的流出量，先算完所有流向、再统一更新（这是方案里定的更新顺序，别边算边改）
- [ ] **低洼聚积**：验证水会停在洼地、越积越深，而不是凭空消失或穿模溢出
- [ ] **固定河道**：持续在一点注水，观察水流冲刷出稳定路径（这是"河道感"的来源）
- [ ] **可视化**：水用半透明蓝色叠加在卫星风格地形上，水位越深颜色越深，能直观看出哪里积住了水
- [ ] **手感自测**：连续玩 10 分钟，记录"看着爽不爽"——这是第 2 周末止损判断的依据

## P1 — 应做（配套动作）

- [ ] **录一段演示视频**：注水→流动→聚积→成河，30 秒~1 分钟即可，发给讨论伙伴一起判断手感
- [ ] **建 GitHub 仓库并首次提交**：Student Pack 已注册，本周代码必须入库（养成每周提交的习惯）
- [ ] **开发日志第 1 期素材**：按"缘起 → 现状 → 下一步"三段式记笔记/录素材，哪怕这周不发，素材先攒着

## P2 — 可选（有余力再做）

- [ ] 给水源加一个简单交互：鼠标点哪里，哪里下雨/注水
- [ ] 地形编辑试玩：允许玩家临时抬/降地形，看水流如何改道（为"挖渠引水"玩法探路）
- [ ] 企划书另存 v0.2 的草稿备忘（原件不动，记录本周原型暴露的问题即可）

## 本周不做（明确排除）

- ❌ 湿润/种植/扩散/NDVI 渐变 —— 那是第 3-4 周核心循环的事
- ❌ 变化检测任务、无人机视角 —— 第 5-6 周
- ❌ UI 美化、音乐、叙事 —— 第 7-8 周
- ❌ 大创申报、Steam 页面 —— 还早

## 周末自检（对照方案"止损护栏"）

- [ ] 水流动是否自然可信？洼地积水是否符合直觉？
- [ ] 连续注水 10 分钟，是否还愿意看？（"看着爽不爽"是硬指标）
- [ ] 若手感不成立 → 触发止损预案：回退为纯变化检测解谜版
