# 《绿脉》（暂定名）项目企划书 v0.1

> 一句话介绍：一款以卫星影像为视角、以生态修复为玩法的 2D 单机游戏——你扮演一套轨道生态修复系统，让荒芜的大地重新变绿。

## 一、项目缘起

我是一名遥感科学与技术专业的本科生。专业课里有一个任务叫"变化检测"——对比同一区域不同时相的卫星影像，找出哪里变了；也有 NDVI 植被指数、DEM 地形分析这些概念。这些知识很酷，但始终停留在课本和数据里。

所以我想把它们做成游戏：**如果玩家能亲手操作一片大地，看着它在卫星图上从红褐色渐变成深绿色，遥感就不再是抽象的概念。**

同时，AI 工具（编程助手、AI 绘图/音乐）让一个人做游戏成为可能。这个项目本身就是一次"专业 + AI + 独立游戏"的实验，全程公开开发日志。

## 二、核心玩法

**类型**：生态修复模拟 / 治愈系策略
**视角**：卫星正俯视为主操作视角（画面就是一幅活的遥感影像）；斜俯视低空漫游为观赏模式（"无人机巡查"），双视角一键切换，分工不对称——精确操作在卫星视角完成，漫游视角用于欣赏成果。

**核心循环（最小闭环）**：

1. **引水**：挖掘水渠，利用地形让水自然流动（基于高度场的简单水文模拟）
2. **润土**：水流经过的土地逐渐湿润
3. **种植**：在湿润的土地上播种
4. **扩散**：植被向周边适宜区域自然蔓延
5. **验收**：区域 NDVI 达标、生态稳定即修复成功

**嵌套玩法——变化检测任务**：修复过程中会触发"卫星过境巡查"事件，系统发放变化前后的两张影像，玩家限时找出退化/受损区域（火灾、洪水、干旱），找对位置可获得精准修复资源。把专业课的看家本领做成玩法模块。

## 三、设计原则

- **小而完整**：首发只做一个生物群系（干旱河谷）、一条机制链（水→土→草→扩散）、5-6 张手工地图
- **能砍则砍**：3D、联机、科技树、动物系统、程序化生成——全部列入"以后再说"
- **遥感不是皮肤，是灵魂**：数值不用抽象血条，用植被指数；配色用遥感标准色带；水文做得更物理——因为这就是专业
- **范围控制优先级最高**：宁可砍功能，不许烂尾

## 四、开发路线

| 阶段 | 周期 | 目标 |
|---|---|---|
| 原型验证 | 第 1-2 周 | 水沿高度图流动、点出湖泊与小河；自测"看着爽不爽" |
| 核心循环 | 第 3-4 周 | 湿润→种植→扩散→NDVI 渐变，一张地图完整通关 |
| 内容与关卡 | 第 5-6 周 | 5-6 张地图、变化检测任务、无人机漫游视角 |
| 润色与首发 | 第 7-8 周 | UI、音乐、叙事外壳，itch.io 免费上架 + Steam 页面筹备 |

**止损护栏**：若第 2 周末核心手感不成立，回退为纯变化检测解谜版，保证 8 周内出成品。

## 五、技术栈

- **引擎**：Godot 4（GDScript 与 Python 语法高度一致，迁移成本最低）
- **地形**：高度图驱动，128×128 格值噪声生成
- **水文**：元胞自动机——按总水位（地形高度+水深）向邻格流动，先算流向后统一更新
- **植被**：湿度场 + 扩散规则，NDVI 色带实时映射渲染
- **版本管理**：GitHub（已注册 Student Pack）
- **AI 工具**：编程助手全程辅助；概念图、音乐音效用 AI 出底稿 + 人工把关
